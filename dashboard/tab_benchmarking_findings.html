What drives error most — country, crop, or model choice?

Country identity explains 73% of the variance in log NRMSE, crop 2%; model choice only 4%. The 20% residual absorbs interactions and unexplained variation. Model effects are real (F = 12.07, p < 0.001) but small relative to task difficulty.

That said, within each task the best model wins by meaningful margins — model choice still matters at the task level. Based on 17 ML architectures across all 62 tasks.

Only tabpfn consistently beats climatology (skill vs clim = ++4.8%). No model reliably beats the 3-year rolling mean: tabpfn comes closest (-5.3%). The rolling-3 is a surprisingly hard baseline to beat in crop forecasting.

A8

Do yield time-series properties predict model skill?

Yes — strongly. Yield trend-strength (predictability of baselines) is the dominant task-difficulty signal: Spearman ρ ≈ −0.7 to −0.8 (p < 0.001) for all 5 models. Tasks in the weakest trend-strength tercile (climatology is the best baseline) achieve median oracle skill +8.8%; strongest trend tasks (rolling-3 easily beats clim.) reach -40.5% — because those tasks have strong persistence that ML cannot beat.

How much is gained by picking the best model per country?

Oracle (theoretical upper bound assuming perfect per-country model selection) achieves +2.4% skill vs rolling-3. Best single model (tabpfn) achieves -8.3%. The gap is +10.7 pp — this is the maximum benefit of a perfect routing strategy.

What is oracle? Oracle is not a real model — it is a theoretical benchmark. For each country, we ask: "if you knew in advance which of the 5 models would work best here, how much better would you do?" The oracle picks the winner per country with perfect hindsight. The +10.7 pp gap over tabpfn shows how much performance is left on the table by using a single model everywhere. Closing this gap requires a meta-learner or routing model that predicts which base model works best per region.

Tasks in the weakest trend-strength tercile (climatology is the best baseline) achieve median oracle skill +11.7%; strongest trend tasks (rolling-3 easily beats clim.) reach -40.8% — because those tasks have strong persistence that ML cannot beat.

Does the admin level (NUTS-1, 2, 3) change accuracy?

Finer admin level (NUTS-3) is NOT harder than NUTS-2 for wheat: median NRMSE is 0.174 at NUTS-2 and 0.198 at NUTS-3. Within Europe, NUTS-3 resolution often benefits from smaller, more homogeneous yield areas.

Do Koppen climate zones explain model performance for wheat?

Arid/Semi-arid (B — EL, ES) is surprisingly easy for all models (positive skill). Continental/Boreal (D) is by far the hardest zone for wheat, especially for CNN-LSTM (−45.3%). tabpfn and LPJmL perform comparably in D-zone wheat (−6% to −8%).

Notes & methods

  • 5 representative models: cnn-lstm (CNN-LSTM daily, trained), patchtst (patchtst daily, trained), xlinear (xlinear daily, trained), tabpfn (tabpfn finetuned dekad), lpjml (lpjml_rainfed, calibrated).
  • ANOVA: 17 ML models — 14 TST architectures at daily resolution (benchmarkArchitectureResults.csv) + tabpfn finetuned dekad + tabicl dekad + tabdpt weekly (benchmarkResolutionResults.csv). LPJmL excluded (process model, different family). Type-I sequential SS.
  • Friedman rank (crop-specific): ranked per task on skill_rmse_vs_rolling3 (1=best) within the 5-model set, then averaged.
  • Rank-frequency heatmap: rank positions within the full 16-model field (14 daily architectures + tabpfn finetuned dekad).
  • Skill formula: skill = 1 − RMSE_model / RMSE_reference. Positive = model beats the reference. Rolling-3 = 3-year rolling mean of observed yields.
  • Oracle: theoretical upper bound from perfect per-country model selection among the 5 representative models.
  • Trend-strength proxy: 1 − min(rmse_ref_trend, rmse_ref_rolling3, rmse_ref_clim) / rmse_ref_clim per task.
  • Koppen Mixed/Large (M): AR, AU, BR, CN, IN, US — countries spanning multiple major climate zones; assigned separately to avoid zone misclassification.
  • Data: CY-Bench v1.0, end-of-season horizon, 5-year fixed test split. mitra excluded (NRMSE > 1.5).
