What drives error most — country, crop, or model choice?

A8

Do yield time-series properties predict model skill?

Yes — strongly. Yield trend-strength (predictability of baselines) is the dominant task-difficulty signal: Spearman ρ ≈ −0.7 to −0.8 (p < 0.001) for all 5 models. Tasks in the weakest trend-strength tercile (climatology is the best baseline) achieve median oracle skill +31.6%; strongest trend tasks (rolling-3 easily beats clim.) reach +9.4% — because those tasks have strong persistence that ML cannot beat.

How to read this table: This analysis tests whether simple yield time-series properties — the strength of a temporal trend (Mann–Kendall p-value) and the training sample size — predict cross-country differences in model skill (skill vs rolling-3). A significant p-value (< 0.05) means that property helps explain why a model does well in some countries but not others. For example, if Trend p is significant for tabpfn, it means tabpfn's advantage is partly explained by whether the country's yield series has a strong temporal trend. This matters for model selection: if trend-strength predicts skill, practitioners can use that property to choose between models without running the full benchmark.

What is oracle? Oracle is not a real model — it is a theoretical benchmark. For each country, it picks whichever of the 5 representative models has the highest skill vs rolling-3 on the test set. In practice, you’d need a held-out validation split per country to select the winner, which reduces training data.

Notes & methods

  • 5 representative models: cnn-lstm (CNN-LSTM daily, trained), patchtst (patchtst daily, trained), xlinear (xlinear daily, trained), tabpfn (tabpfn finetuned dekad), lpjml (lpjml_rainfed, calibrated).
  • ANOVA: 17 ML models — 14 TST architectures at daily resolution (benchmarkArchitectureResults.csv) + tabpfn finetuned dekad + tabicl dekad + tabdpt weekly (benchmarkResolutionResults.csv). LPJmL excluded (process model, different family). Type-I sequential SS.
  • Friedman rank (crop-specific): ranked per task on skill_rmse_vs_rolling3 (1=best) within the 5-model set, then averaged.
  • Rank-frequency heatmap: rank positions within the 5 representative models, ranked on skill_rmse_vs_rolling3.
  • Skill formula: skill = 1 − RMSE_model / RMSE_reference. Positive = model beats the reference. Rolling-3 = 3-year rolling mean of observed yields.
  • Oracle: theoretical upper bound from perfect per-country model selection among the 5 representative models.
  • Trend-strength proxy: 1 − min(rmse_ref_trend, rmse_ref_rolling3, rmse_ref_clim) / rmse_ref_clim per task.
  • Koppen Mixed/Large (M): AR, AU, BR, CN, IN, US — countries spanning multiple major climate zones; assigned separately to avoid zone misclassification.
  • Data: CY-Bench v1.0, end-of-season horizon, 5-year fixed test split. mitra excluded (NRMSE > 1.5).
